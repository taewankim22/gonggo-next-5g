공고다음 전국 공고 수집

범위
- 전국 공통 및 17개 시도 × 장학금·공모전·대외활동: 54개 검색어.
- 전국 공통 검색은 연도를 제한하지 않아 다음 해 모집도 찾는다.
- 지역 검색은 현재 연도를 사용한다. Tavily 기본 검색으로 검색어당 최대 20개 링크를 확인한다.
- 최근 한 달 게시·수정 결과를 검색하며, 검색 제공사가 날짜를 모르는 결과도 포함될 수 있다. 접수 상태는 원문으로 따로 확인한다.
- 알려진 공고 모음 사이트·블로그·SNS는 검색에서 제외하고 기관 원문을 우선한다.
- 지역 제한 없이 공개 기관·기업·대학 문서를 후보로 받는다. 전국 공고의 전수 수집을 보장하지 않는다.
- 등록 기관 게시판은 보조 출처다. 검색 API가 없으면 전국 검색 완료로 표시하지 않는다.
- 검색 결과와 프로필을 섞지 않는다. 본문을 읽은 뒤 기존 조건별 판정표로 대조한다.

검색 연결
1. https://app.tavily.com/ 에서 무료 계정을 만들고 API Keys의 키를 확인한다.
2. 임시 테스트: 앱 메뉴 → 전국 검색 연결 · Tavily → API 키 입력.
   직접 입력한 키는 현재 세션에서만 사용하며 브라우저 답변 저장에 포함하지 않는다.
3. 팀 공용: Streamlit 앱 Settings → Secrets의 기존 내용 아래에 다음을 추가한다.
   기존 [team] 설정은 유지한다. 키를 채팅·저장소·스크린샷에 넣지 않는다.

[search]
api_key = "발급된 Tavily API 키"

로컬은 .streamlit/secrets.toml 또는 TAVILY_API_KEY 환경변수를 지원한다.
이 파일은 저장소에서 제외되어 있다.

비용과 재사용
- 확인일 2026-10-14: Tavily Researcher 무료 플랜 월 1,000크레딧, 카드 등록 불필요.
- 기본 검색 1회 1크레딧. 전체 새 검색 54크레딧, 같은 검색은 15분간 재사용한다.
- 무료 할당량이 끝나면 검색 실패를 표시한다. 코드는 자동 결제·플랜 변경을 하지 않는다.
- Upstage 원문 분석 크레딧은 별도다. 운영자가 이미 승인한 팀 연결을 사용한다.
- 네이버 구현 안내는 사용하지 않는다. 신규 발급 경로 변경 및 검색 데이터의 AI 활용 제한을 확인해 Tavily로 변경했다.

수집 및 분석
- 원문 수집은 공개 네트워크 주소를 검증하고 robots.txt 제한을 따른다.
- 모음 사이트 링크는 주최기관 원문이 필요하다고 표시한다. 자동으로 우회 수집하지 않는다.
- 본문과 포스터, 지원 첨부 최대 10개를 처리한다. 지원하지 않는 사이트·이미지·첨부는 경고한다.
- 한 번에 분석할 공고 수는 처리 묶음이다. 전체 검색 범위를 제한하지 않는다.
- 발견한 공고·미완료 공고는 대기 목록에 보존한다. 직접 선택하거나 이어서 처리한다.
- 동일 URL의 추적·표시 파라미터는 제거하되 모집 회차·공고 ID는 유지한다.
- 분석은 원본 바이트 해시와 Agent ID/설정 버전이 모두 같을 때만 재사용한다.
- 여러 출처의 공고는 제목과 전체 분석 문서가 모두 같고 누락·경고가 없을 때만 한 카드로 묶는다.
  제목이 같거나 공통 신청서만 같다는 이유로 모집 연도·회차를 합치지 않는다.
- 원문 변경 후 새 분석이 실패하면 예전 내용을 최신 조건으로 추천하지 않는다.
- 공개 목록은 현재 Streamlit 서버의 로컬 디스크에 저장되어 재배포·초기화 시 없어질 수 있다.
- 검색 키와 Upstage 키, 개인 프로필·답변은 공개 목록·검색 캐시에 저장하지 않는다.

검증 범위와 실제 실행 결과는 verification/nationwide_20261014에 별도 기록한다.

제한과 추가 검증
- 검색 요약문은 지원 자격 근거로 사용하지 않는다.
- 제목상 합격·면접 대상자 발표 등 후속 안내는 자동 모집 분석에서 제외하되 후보 목록에는 남긴다.
- 사업 연도만 보고 접수 연도를 확정하지 않는다. 근거가 없는 접수 마감은 확인 필요다.
- 여러 사용자의 첫 검색이 겹치면 검색 요청이 중복될 수 있다. 문서 분석에는 별도 실행 잠금이 있다.
- 자동 테스트 통과는 전국 모든 사이트 지원이나 전체 추출 정확도를 의미하지 않는다.
