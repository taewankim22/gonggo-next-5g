공고다음 · 암호 없는 공개 테스트 설정

아래 설정을 Streamlit 관리 화면 → 앱 Settings → Secrets에 입력합니다.
API 키는 Secrets 화면에서만 채우세요. 이 파일이나 GitHub에 저장하지 마세요.
기존 [team] 설정이 있으면 중복 추가하지 말고 수정합니다.

[team]
enabled = true
require_password = false
api_key = "여기에_본인_Upstage_API_키"
notice_id = "agt_bmPkaZ9TyocTVn7Nw4BEbh"
notice_version = "4"
review_id = "agt_joPSsuMsD6vr7zNLzicGve"
review_version = "2"
daily_limit = 0

Save 후 사이트를 새로고침합니다. 동료에게는 사이트 주소만 공유하세요.
공개 테스트는 누구나 운영자 크레딧으로 호출할 수 있습니다.
하루 호출 횟수 제한은 없습니다. 동시 1건·간격 10초는 유지합니다.
호출 횟수는 한국 시간 기준으로 집계합니다. Upstage 크레딧과 서비스 제한은 별개입니다.
키를 교체할 때는 Secrets의 api_key를 수정하세요. 새 키로 두 Agent에 접근할 수 있어야 합니다.
중단 시 enabled=false, 암호 접속으로 바꾸려면 require_password=true와 12자 이상 password를 설정하세요.
