공고다음 · 5G
공고 속 조건을, 내 다음 행동으로.

서비스: https://gonggo-next-5g-gjkapf7kye4lzappppjuy9s6.streamlit.app/
코드: https://github.com/taewankim22/gonggo-next-5g

무엇을 하나요?
대학생이 장학금·대외활동·공모전 공고를 올리고 본인 상황을 답하면,
지원 조건, 제출서류, 준비 시점과 다음 행동을 정리합니다. 선발이나 최종 지원 자격은 결정하지 않습니다.

화면
홈: 내 정보 등록(선택) → 공고 직접 확인하기 또는 나에게 맞는 공고 보기.
공통 프로필은 같은 브라우저에서 재사용하고 공고별 답변·체크·지원 단계는 분리합니다.
1. 공고 넣기: PDF, HWP 5.x, HWPX, JPG/JPEG, PNG (15MB 이하, PDF 1~30쪽).
2. 핵심 확인: 지원 대상·제출 경로·마감·원문 확인.
3. 내 상황: 공고에 연결된 질문에 답변. 모르는 항목은 비워 둡니다.
4. 준비 목록: 다음 행동, 조건별 독립 판정표, 현재 서류, 이후 단계 서류, 상세 AI 검토.
인스타 색상의 4단계 화면이며 모바일에서는 판정표가 세로로 배치됩니다.

조건별 독립 판정 (2026-10-13)
- 학적·잔여학기·횟수·시간 등 원문 근거와 대조 가능한 항목을 각각 판정합니다.
- 확인된 수치 불일치는 다른 조건의 미입력 때문에 사라지지 않습니다.
- 자유서술 답변은 입력됐다는 이유만으로 개별 일치 판정하지 않습니다. AI 범주 검토를 별도로 확인합니다.
- 서류 이름과 원문의 상위 절을 연결해 시점을 정합니다. 후속연구 절은 다음 페이지에도 이어집니다.
- 이후 단계와 시점 미확정 서류는 현재 필수 누락 목록에서 분리합니다. 적용 대상 아님과 이후 단계는 다릅니다.
- 대상 여부와 준비 상태는 자기 확인이며 실제 증빙 내용·진위·접수 완료를 검증하지 않습니다.
- TXT와 검토 JSON에 독립 판정·원문 근거·시점을 포함합니다.

Upstage 구조 (2026-10-14, 공고 분석 설정 13)
공고 원본 → Parse → Classify(장학금 / 대외활동·봉사 / 대회·공모전 / 기타)
→ 해당 유형의 Extract(한국어 원문 사실·조건·서류·일정·혜택 표)
→ 해당 유형의 Instruct(현재 준비 / 이후 준비 / 불일치·미확인 / 다음 행동)
→ 기존 앱의 질문·체크리스트·조건별 독립 검증으로 연결합니다.
Classify는 문서 유형을 나누며, 한 문서를 여러 Extract에 무조건 보내지 않습니다.
각 경로에는 유형별 추출 지침과 후속 검토 지침이 있습니다.
앱 내부에서는 새 표를 기존 비교 형식으로 변환하며 원본 표도 보존합니다.
개인 답변 대조는 기존 맞춤검토 Studio [Parse → Extract, 설정 2]를 유지합니다.
공고 Instruct 안내는 개인 합격·자격 판정이 아닙니다.
내보내기: agent_configs/notice.mission2.export.json(설정 13), review.mission2.export.json(설정 2).

검증 범위와 한계
HWPX 인공지능 챔피언 공고, 현대점프스쿨 PDF, 통영 공모전 PNG, 학과 장학금 HWP로 실호출했습니다.
전체 연구지원 규모와 개인 금액, 현재 신청 서류와 이후 협약 서류를 구분합니다.
원문과 일치하는 인용만 근거로 사용하며, 유일하게 찾은 인용에 한해 페이지를 보정합니다.
Parse의 표 구분자만 제거해 대조하고 문장·숫자 누락은 허용하지 않습니다.
Studio Extract가 신고증의 신청 시점을 현재로 분류한 사례는 앱이 상위 후속연구 절로 다시 확인해 이후 단계로 분리합니다.
포스터 표의 일부 인용·금액 단위는 아직 직접 확인이 필요합니다. 미확인 지급 단위를 개인당으로 확정하지 않습니다.
한쪽에서 생략된 시각과 상세 본문의 보완 정보를 충돌로 취급하지 않도록 검토 지침을 보완했습니다.
10쪽 HWPX 분석은 이번 실행에서 약 4분 30초가 걸렸습니다. 호출 대기는 최대 10분이며 자동 재시도하지 않습니다.
기존에 저장된 공고는 당시 결과를 유지합니다. 새 설정 적용 결과를 보려면 실제 AI 분석으로 다시 실행하세요.

다른 계정은 워크플로우를 가져온 뒤 자신의 Agent ID·Config ID로 연결해야 합니다.

내 컴퓨터에서 실행 (Python 3.12 권장)
python -m venv .venv
Windows: .venv\Scripts\python.exe -m pip install -r requirements.txt
Windows: .venv\Scripts\python.exe -m streamlit run app.py
macOS/Linux: .venv/bin/python -m pip install -r requirements.txt
macOS/Linux: .venv/bin/python -m streamlit run app.py
개인 모드에서는 연결 설정에 자신의 API 키와 Agent ID를 입력합니다.
공유 모드는 TEAM_SETUP.txt 안내대로 Streamlit Secrets를 설정합니다. 키를 코드에 쓰지 마세요.

저장·개인정보
공고 원본·본문, 답변·체크·현재 단계는 해당 브라우저 IndexedDB에 저장됩니다.
API 키·실행 로그·상세 AI 결과는 브라우저 자동 저장에서 제외됩니다.
같은 주소·브라우저 프로필에서 복원되며 기기 간 동기화 기능은 없습니다.
저장 버전 2는 기존 v1 기록을 보존해 이전합니다. 여러 탭 저장 충돌은 덮어쓰기 대신 백업·새로고침을 안내합니다.
공용 컴퓨터에서는 설정의 저장 내용 지우기를 사용하세요. 개인 계정으로 암호화된 저장소가 아닙니다.
실제 분석 시 원본과 비교 PDF가 앱 서버를 거쳐 Upstage로 전송됩니다.
공급자의 파일·실행 보존은 해당 서비스 정책과 계정 설정을 따릅니다. 결과 JSON 공유 전 답변을 확인하세요.

공개 테스트 운영
현재는 사용자가 선택한 무암호·일일 횟수 무제한 모드입니다. 방문자가 운영자의 크레딧을 사용합니다.
서버 Secrets의 키는 방문자 브라우저에 저장하지 않습니다. 동시 1건과 10초 간격 보호는 유지합니다.
공고 분석과 맞춤검토는 각각 별도 호출입니다. 대기 시간 초과·실패 시 자동 재호출하지 않습니다.
개인 모드의 직접 입력 키는 세션에서만 사용합니다. 제공사 사용량·크레딧 제한은 별개입니다.

배포
Streamlit Community Cloud에서 이 저장소 main 브랜치의 app.py를 실행합니다.
설정은 Cloud Secrets를 사용하며 .env·실제 키·사용자 실행 기록을 GitHub에 올리지 않습니다.
소스 변경을 main에 반영하면 배포 앱에 적용됩니다. 적용 후 화면과 실제 호출을 별도로 검증합니다.

검증
python -m pip install pytest
python -m pytest tests -q
공개 저장소의 테스트는 저장·호출 보호·조건 분리·실제 공개 문서의 단계 구분을 검증합니다.
전체 개발 작업 공간에는 별도의 문서 입력·앱 흐름·실제 API 실행 기록이 있습니다.
테스트 개수나 스키마 통과는 전체 추출 정확도를 뜻하지 않습니다.

한계
자유서술·복합 조건, 흐린 이미지, 잘못된 OCR, 인용 연결, 원문 자체의 충돌은 확인 필요가 남을 수 있습니다.
독립 표의 일치는 해당 수치나 자기 확인 항목만을 뜻하며 전체 자격이나 증빙 유효성을 보장하지 않습니다.
같은 서류가 여러 시점에 나오거나 시점 근거를 연결하지 못하면 제출 시점 확인 필요로 남깁니다.
HWP/HWPX는 Studio 변환 본문을 근거로 사용하며 원본의 시각적 페이지와 다를 수 있습니다.
자동 검색은 공고별 본문·지원되는 첨부를 각각 분석해 조건을 함께 보여줍니다. 문서 간 예외의 우선관계·정정 공고 해석, 자동 지원, 개인 계정·기기 동기화는 구현하지 않았습니다.
390px 모바일 및 별도 사용자 기기 간 격리는 이번 확장에서 미검증입니다.
실제 사용자 시간 절감과 일반 정확도는 아직 측정하지 않았습니다.

프로필과 공개 공고 목록 (2026-10-13)
이번 공고 답변 → 기준 시점이 맞는 프로필 → 확인 필요 순으로 적용합니다.
이번 공고에서 명시한 모름은 프로필로 다시 채우지 않습니다. 성적 만점·학기 불명, 복합 OR는 확정하지 않습니다.
공식 출처의 PDF 1·포스터 2·HWP 2를 Studio 설정 7로 분석해 초기 카탈로그 5개를 배포했습니다.
목록은 아래의 내 정보 기반 우선순위로 표시하며 종류·접수 상태·관심 키워드로 탐색합니다. 자격 충족 확률은 계산하지 않습니다.
프로필 수정·필터·단계 이동은 AI를 호출하지 않습니다. 공개 분석은 원문 해시·설정이 같을 때 재사용합니다.
5문서×3가상 프로필의 선택 조건 15/15 및 자동 테스트 111/111 통과. 전체 추출 정확도 100%라는 뜻이 아닙니다.
배포 사이트의 실제 상세 검토 1회도 확인했습니다. 기존 HWPX 회귀는 과거 실제 추출 기록을 재생했습니다.

인터넷 공고 수집·분석 (2026-10-14 연결)
기존 contest-agent의 공개 HTTP 수집 부분만 public_network.py에 재사용했습니다.
python collect_notices.py --output verification/discovery/collected --limit 3
웹앱: 내 정보 → 저장하고 최신 공고 찾기. 이미 저장했다면 공고 찾기 → 최신 공고 찾기.
본문·포스터와 지원되는 첨부를 자동 수집·분석합니다. 기본 최신 3개이며 검색 범위에서 1·3·5·10개를 선택합니다. 일일 호출 한도와는 별개입니다.
개별 문서 선택 흐름은 '공고·문서를 직접 골라 분석하기'에서 계속 사용할 수 있습니다.
연결된 출처는 세종대학교 공식 장학 게시판 첫 페이지입니다. 전국 공고 통합 검색이 아닙니다.
게시글 본문은 표의 병합 셀·각주·본문 이미지를 보존한 분석용 PDF로 재구성합니다. 페이지 번호는 이 재구성본 기준입니다.
첨부 PDF·HWP·HWPX·JPG·PNG는 원본 분석합니다. 본문 이미지 최대 6개, 수집 첨부 최대 5개이며 지원 불가·다운로드 실패·분석 실패는 확인 필요로 표시합니다.
공고별 문서를 한 카드에 모아 각 문서의 독립 조건을 대조합니다. 문서 간 마감일이 다르면 접수 상태 확인 필요로 남깁니다.
한 문서의 실패가 다른 공고 분석을 막지 않습니다. 변경된 문서 분석이 실패하면 이전 분석을 최신 조건으로 사용하지 않습니다.
분석은 기존 팀 연결과 config13을 사용합니다. 실패·형식 오류·근거 본문이 없는 결과는 목록에 추가하지 않습니다.
공개 원문·완료 결과·서버 실행 ID는 runtime/public_catalog.sqlite3에 저장하며 개인 프로필·답변·API 키를 포함하지 않습니다.
같은 출처·원문 해시·설정 버전의 완료 결과는 추가 호출 없이 재사용합니다. 동시 요청은 잠그고 실행 ID가 있으면 재조회합니다.
제출 성공 여부가 불명확하고 실행 ID가 없으면 자동 재실행하지 않습니다. 운영자가 Studio 실행 내역을 확인해야 합니다.
공용 목록은 현재 Streamlit 인스턴스 이용자에게 공유됩니다. 서버 재배포·초기화 때 동적 목록은 사라질 수 있습니다.
검토 화면으로 연 공고와 개인 답변은 기존 브라우저 저장 방식으로 유지합니다. 정기 수집은 연결하지 않았으며 사용자가 버튼으로 가져옵니다.
URL 중복 제거, HTML·첨부 해시 및 확인 시각을 기록합니다. HTML 해시 변경은 조회수 등의 영향도 받을 수 있습니다.
운영 DB·Slack·자동 작업 생성 경로는 연결하지 않습니다. 수집 실패를 우회하지 않습니다.
data/catalog의 기본 5건과 런타임 AI 분석 목록을 함께 표시합니다. AI 분석 완료는 사람이 전체 조건을 검증했다는 뜻이 아닙니다.

내 정보 기반 우선순위 (2026-10-14)
마감일이 지난 공고는 뒤로 보내고, 나머지는 확인된 지원 자격 불일치가 없는 공고를 먼저 표시합니다.
그 안에서 원문으로 확인된 지원 자격 일치 → 우대 조건 일치 → 관심 분야 키워드 → 일정 순으로 표시합니다.
미입력 수는 순위 점수로 사용하지 않으며 미입력·근거 불명·기준 시점 불일치는 확인 필요입니다.
우대 불일치나 서류 미준비는 지원 자격 불일치로 계산하지 않습니다. 확인된 불일치가 미입력 때문에 사라지지 않습니다.
개인별 정렬은 공통 프로필로 즉시 다시 계산하며 별도 AI 호출이나 공유 저장을 하지 않습니다.
공고별 '03 내 상황'의 답변을 공통 프로필로 자동 승격하지 않습니다. 상세 검토에서는 기존 공고별 답변 우선 규칙을 유지합니다.
